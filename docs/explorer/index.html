Featured Global Sustainability Explorer

Seventeen goals. Every country. One place.

A free, open tool for researchers to explore, compare and cite global sustainability data for all 17 Sustainable Development Goals in one place. It brings together the UN SDG Global Database, the World Bank's World Development Indicators and Our World in Data, updates itself as new releases come out, and follows sustainability news from the UN and its conferences.

  • 17 SDGs
  • 3 open data sources
  • 260+ countries and territories
  • Updated automatically
  • Drill down by goal. Goal → target → indicator → breakdown (sex, age, urban/rural), for any country, region or year range.
  • Always current. An automated pipeline checks every source every few hours, downloads only what changed, validates it and logs each update.
  • Chart, map, table. Compare countries over time, play a world map through the years, and download CSV with source columns.
  • Live news and conferences. Headlines from UN and specialist newsrooms tagged by SDG and country, with UN conferences such as COP31 tracked.

Python · pandas · DuckDB / Parquet · GitHub Actions · JavaScript · Observable Plot · GitHub Pages · Data: UN SDG Global Database, World Bank WDI and Our World in Data, each under its own licence.
